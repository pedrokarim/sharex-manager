Auto-hébergement en quelques minutes

Le serveur tourne sur Bun, en production via Docker.

# Production (Docker)
git clone https://github.com/pedrokarim/sharex-manager.git
cd sharex-manager
bun install
bun run setup                   # URL, port, authentification, premier administrateur
docker compose up -d --build

Développement : bun install, bun run setup puis bun dev. L’assistant crée le premier administrateur ; les comptes suivants se créent depuis l’administration. Détails dans la page Installation.
